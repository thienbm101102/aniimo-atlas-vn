# Aniimo Atlas VN — Stable UI v5

This build keeps the original MinMax data and assets intact and applies a clean responsive UI layer.

## UX fixes in v5
- One scroll surface on mobile/tablet for the control drawer.
- No nested-scroll trap in layer/item/checklist content.
- Drawer width is constrained so the interactive map remains visible.
- Long labels stay inside cards and do not stretch the layout.
- Settings is a bounded, scrollable modal.
- CSS cache version bumped to v5.

The files under `data/` and `assets/` (except the added Vietnamese i18n file) remain unchanged from the supplied MinMax source.
