Một web companion hiện đại dành cho người chơi Aniimo — kết hợp bản đồ tương tác, dữ liệu Aniimo, kho vật phẩm, checklist, theo dõi hồi sinh và Team Builder trong một giao diện duy nhất.

✦ Giới thiệu

Aniipedia Việt Nam được xây dựng lại từ nền tảng Aniipedia gốc với mục tiêu mang đến trải nghiệm tra cứu và khám phá Aniimo trực quan hơn, đặc biệt trên màn hình desktop nhưng vẫn có khả năng thích ứng với tablet và mobile.

Logic bản đồ, dữ liệu và các luồng tương tác quan trọng của source được giữ lại; phần giao diện được tổ chức lại theo design system mới.

✓ Checklist

Checklist giúp theo dõi tiến độ hoàn thành các nội dung trong game.

⚡ Chạy local

Aniipedia là website static và không bắt buộc phải có backend để chạy phần giao diện chính.

Từ thư mục project:

python -m http.server 5173

Sau đó mở:

http://127.0.0.1:5173/

Không nên mở trực tiếp index.html bằng file:// nếu trình duyệt chặn các request dữ liệu JSON. Chạy qua HTTP local sẽ đúng với môi trường triển khai thực tế hơn.

🚀 Deploy GitHub Pages

Project đã có workflow GitHub Pages tại:

.github/workflows/deploy-pages.yml

Các bước cơ bản:

Đưa toàn bộ project lên repository GitHub.

Giữ data/, assets/, index.html, các file JavaScript và workflow ở đúng cấu trúc.

Vào Settings → Pages và chọn GitHub Actions.

Push lên branch main.

Chờ workflow Deploy to GitHub Pages hoàn tất.

Mở URL dạng:

https://USERNAME.github.io/REPOSITORY/

Lưu ý quan trọng

Aniipedia được xử lý path để hoạt động với GitHub Pages project site. Không cần di chuyển data/ hoặc assets/ lên domain root.

Không mở website bằng:

https://github.com/USERNAME/REPOSITORY/blob/main/index.html

Đó là giao diện xem file của GitHub, không phải môi trường chạy website.
