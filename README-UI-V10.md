# Aniimo Atlas VN — UI v10

Bản UI v10 giữ nguyên dataset và asset của MinMax-Aniipedia, chỉ thay presentation layer và bổ sung metadata hiển thị cho các thẻ lớp.

## Điểm chính
- Font: Be Vietnam Pro + Space Grotesk (Google Fonts).
- Bố cục sidebar dùng container query để tự thích ứng theo **chiều rộng sidebar thực tế**, không phụ thuộc breakpoint viewport.
- Thẻ lớp có icon, tên, số loại, số vị trí và trạng thái "Đang xem/Xem lớp".
- Scroll lớp được làm gọn, không còn scrollbar dọc lộ ra giữa giao diện.
- Văn bản dài được ellipsis, không tràn card.
- Changelog/Popup nhật ký cũ đã loại khỏi UI.
- Không thay đổi thư mục `data/` và `assets/`.

## Cập nhật repo hiện tại
Chép đè `index.html`, `app.js`, `atlas-vn-ui.css` vào repository hiện tại rồi Commit/Push bằng GitHub Desktop.
